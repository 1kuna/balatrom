# Install guide

[← Back to BalatROM](README.md) · [FAQ](docs/FAQ.md) · [Report a bug](https://github.com/1kuna/balatrom/issues)

## Before you start

- Install **Balatro from Steam** and make sure it's on version **1.0.1o**.
- Grab a Game Boy Color emulator. [SameBoy](https://sameboy.github.io/) is a good pick.

## 1. Download

Get the latest version from the [Releases page](https://github.com/1kuna/balatrom/releases/latest):

- **Mac (Apple Silicon):** `BalatROM-1.0.0-macOS-arm64.zip`
- **Windows (64-bit):** `BalatROM-Setup-1.0.0-Windows-x64.exe`

Only download BalatROM from that page.

## 2. Install

**Mac:** Unzip it and drag **BalatROM** into your Applications folder, then open it.

> If macOS says it can't check the app, open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**.

**Windows:** Run the setup file and follow the steps.

> Windows may show a blue "Windows protected your PC" screen because the installer isn't signed yet. Click **More info → Run anyway**.

## 3. Build your ROM

1. Open BalatROM. It looks for your Balatro install on its own. If it can't find it, click **Locate…** and point it to your Balatro folder.
2. Click **Build ROM**. The first build downloads a few MB of free build tools, then takes about two minutes.
3. Click **Save ROM…** and pick where to put it. Use a fresh filename so you don't overwrite an older ROM or save.

## 4. Play

Open the `.gbc` file in your emulator. Have fun.

## Something went wrong?

**"Unsupported version":** BalatROM only works with Steam Balatro 1.0.1o right now. If Steam updated the game, keep an eye on this repo for an update.

**Anything else:** [open an issue](https://github.com/1kuna/balatrom/issues) with:

- Your OS (for example, macOS 15.3 or Windows 11)
- What you clicked and what you expected
- The error message, with your name and folder paths removed

Please don't attach Balatro files, ROMs or saves.
