# FAQ

[← Back to BalatROM](../README.md) · [Install guide](../INSTALL.md)

**Do I need to own Balatro?**
Yes. BalatROM builds the ROM from your own Steam copy of Balatro. Without it, there's nothing to build from.

**Can I just download the ROM?**
No, and please don't ask for or share one. The whole point is that everyone builds their own from a copy they bought.

**Which version of Balatro works?**
Only Steam **1.0.1o** right now. Other stores and versions aren't supported yet. Mobile and console versions won't work.

**Does it need my Steam login?**
No. It only reads the game files already on your computer.

**Is this the full game?**
No. It's a Game Boy Color version, so some jokers and features had to go.

**Does it work on a real Game Boy Color?**
It isn't tested on real hardware yet. Flash carts and handhelds might work, but no promises.

**Does it work on the original Game Boy?**
No. It's Game Boy Color only.

**Mac says it can't check the app / Windows says it protected my PC.**
See the [install guide](../INSTALL.md#2-install) for the one-click fix.

**What about Linux?**
There's no Linux version right now.

**Do my desktop runs carry over?**
No. BalatROM saves are separate from desktop Balatro.

**Is this official?**
No. It's a fan project and isn't affiliated with or endorsed by LocalThunk or Playstack.

**Something broke. Where do I report it?**
[Open an issue](https://github.com/1kuna/balatrom/issues). Please leave out game files, ROMs, saves and personal info.
